# NKHONDO — Asset credits

All gameplay code, unit/tower/arena models, textures, UI frame art, VFX and music
in this vertical slice are **original works created procedurally in code** for
Nkhondo (no third-party art is shipped yet). No Clash Royale or other game assets
are used or imitated.

When library assets are introduced (build steps 3–5), every file will be logged
here with source, author and licence. Approved sources only:

- KayKit (Kay Lousberg, CC0) — characters, buildings, props
- Quaternius (CC0) — characters, animals, nature, buildings
- Kenney.nl (CC0) — props, UI, particles, audio, icons
- Poly Pizza — low-poly; prefer CC0, credit CC-BY per item
- Mixamo — humanoid animation retargets (licence per asset)
- Poly Haven / ambientCG (CC0) — HDRIs, subtle textures
- Audio: Kenney (CC0), Sonniss GDC bundles (royalty-free), Freesound (CC0 preferred)
- Icons: game-icons.net (CC BY 3.0, credit each)
- Fonts: Google Fonts — Lilita One (OFL), Inter (OFL)

Rules enforced: no NC/unclear licences, no ripped assets, everything recoloured
to the Nkhondo house style, glTF+Meshopt/KTX2 + UI atlases.

## Shipped so far (original, no credit required)
- Procedural stylised unit/tower/arena meshes (sim + render code)
- Original illustrated card portraits (src/assets/portraits/*.svg, Nkhondo house style)
- Procedural WebAudio music (ngoma/kalimba/guitar-inspired patterns) & SFX
- Chichewa/English UI strings (to be verified by a native speaker pre-release)
